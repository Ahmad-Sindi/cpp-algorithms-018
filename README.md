# Algorithm Challenge
#18 – Circle Area

## 🧮 Problem Description
This challenge focuses on calculating the **area of a circle** when the **radius** is given.  
It’s a fundamental geometry problem that helps strengthen your understanding of formulas and arithmetic in C++.

---

## 🧠 Formula
\[
\text{Area} = \pi \times r^2
\]

---

## 💡 What You’ll Learn
- How to use constants in C++
- How to work with mathematical functions like `pow()`
- Applying real-world math logic inside a program
- Strengthening fundamentals of geometry-based coding

---

## 🧩 Example
**Input:**  
Enter the radius: 7

**Output:**  
The area of the circle is: 153.938
